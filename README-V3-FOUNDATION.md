# V3 — Foundation

V3 established the permanent baseball-data layer that later Living Universe features use.

Highlights include modular pages/components, Firebase synchronization, season archives, permanent finalized-game history, league records, franchise profiles, player careers from Season 4 forward, News, power rankings, rivalries, streaks, playoff history, operator tools, GameCast, animated runners/ball, stolen bases, direct strikeout buttons, and safer reset/season workflows.

V4 and later should be treated as presentation/simulation layers built on top of this foundation rather than replacements for the underlying game history.
