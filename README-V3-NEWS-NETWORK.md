# SMB4 Franchise Central V3 - 24/7 News Network

This update turns the News page into a rotating league network instead of a static list.

## Rotation
- Lead/featured stories rotate every 2 minutes.
- Facts Desk rotates every 90 seconds.
- Live ticker advances roughly every 14 seconds.
- All generated stories remain available in the scrollable All Stories & Nuggets archive.

## New story sources
The generator now uses substantially more of the league database, including:
- league and AL/NL leaders
- playoff cut-line snapshots
- teams above .500
- scoring environment
- run-differential oddities
- current run-differential spread
- V3 game volume
- one-run game rate
- walk-offs and extra innings
- busiest recorded head-to-head matchup
- longest recorded V3 win streak
- teams without trophies
- teams never to reach the World Series
- active playoff droughts
- World Series appearance leaders
- division-title leaders
- #1 seed leaders when available
- repeat-champion history
- existing standings, archive, postseason, record, transaction, injury and award stories

No unrecorded regular-season scores are invented. Everything is derived from data already stored by Franchise Central.
